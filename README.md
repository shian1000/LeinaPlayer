# MusicDatabaseApp

Flutter frontend for [MusicDatabase](../MusicDatabase) — a personal music library / metadata
enrichment tool. Targets Android first, with iOS kept buildable for the future.

Currently a bootstrap app: a single "Hello World" screen, no backend connection yet.

## Setup

```bash
flutter pub get
```

## Run

```bash
flutter run
```

## Tests

```bash
flutter test
```
